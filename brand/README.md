# Hibou brand assets

Approved assets for Hibou. Start with the [press toolkit](press-kit/README.md)
and [brand book](brand-guidelines.md). Solid is the primary identity; outline is
reserved for IDE toolbars. Dedicated 16px cuts preserve eye legibility.

## Quick reference

- **Name / wordmark:** always lowercase — `hibou`.
- **Tagline:** *Eyes on what you ship.*
- **Signature color:** Owl Amber `#FBBF24` — the eyes. Use sparingly.
- **Primary:** Hibou Blue `#58A6FF` · **Base:** Night `#0B0F1A`.
- **Fonts:** Space Grotesk (display), Inter (UI), JetBrains Mono (code).

## Regenerate

Run `cd docs && npm ci && npm run brand`. The generator synchronizes the web
surfaces and an available `hibou-ide/` checkout, creates press assets with
font-independent lettering, and builds the versioned docs download archive.

The source Space Grotesk font and its SIL OFL license live in `fonts/`.
Approved asset exports are checked in; the downloadable ZIP is generated by
`npm run build` in `docs/` and is ignored by Git. Edit canonical masters or the
generator rather than generated copies. Do not alter the eyes-below-brow geometry.
